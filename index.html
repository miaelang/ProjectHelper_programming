자료 이용 안내 · 시범운영 초안

이 서비스는 계정 확인과 프로젝트 학습 지원을 위해 계정 ID, 비밀번호 검증값, 수업, 프로젝트 메모, 대화와 시각, 사용 모델·지침 버전을 맥북의 데이터베이스에 보관합니다. 학생은 본인 기록, 담당 교사는 담당 학생 기록을 볼 수 있습니다.

AI 답변은 이 맥북의 Ollama에서 생성합니다. 웹 화면은 GitHub Pages가 제공하며, 로그인·대화 요청은 Cloudflare의 HTTPS 중계 서버를 거쳐 교사 맥북에 전달됩니다. 외부 AI 서비스에는 보내지 않습니다. CSV를 외부에 업로드하면 별도의 외부 처리가 됩니다.

연구 참여는 수업 이용과 구분하여 안내합니다. 연구 참여 여부를 성적에 반영하지 않으며, 연구용 내보내기는 교사가 별도 절차를 확인한 계정에 한합니다. 대화에는 실명·연락처를 쓰지 마세요.
